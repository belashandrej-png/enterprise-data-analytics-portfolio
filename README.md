# Enterprise Data Analytics Portfolio

**Автор:** Андрей Белаш  
**Цель:** Портфолио проектов по Data Engineering, мониторингу и продуктовой аналитике  
**Статус:** Реализован

## О проекте

Это структурированное портфолио, демонстрирующее навыки в трех ключевых областях:

1. **ETL и Data Pipelines** — построение надежных конвейеров данных
2. **Service Monitoring & Metrics** — мониторинг и метрики сервисов
3. **Product Analytics & BI** — аналитика продукта и визуализация

## Технологический стек

| Область | Технологии |
|---------|------------|
| **ETL/ELT** | Python, Apache Airflow, SQL, dbt |
| **Мониторинг** | Prometheus, Grafana, PostgreSQL |
| **BI/Analytics** | Tableau, Power BI, Metabase |
| **Инфраструктура** | Docker, Git, Linux |
